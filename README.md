## ✨ Tentang Aplikasi

**MikdadStreaming** adalah aplikasi streaming film dan series berbasis Android yang dibangun menggunakan **Kotlin** dan **Jetpack Compose**. Dirancang dengan antarmuka modern, navigasi simpel, dan pengalaman menonton yang mulus — kapan saja, di mana saja.

## 🚀 Fitur Unggulan

| Fitur | Deskripsi |
|-------|-----------|
| 🏠 **Beranda** | Daftar film dan series terbaru dalam tampilan yang rapi |
| 🎯 **Rekomendasi** | Saran tontonan yang dipilih khusus untukmu |
| 🔍 **Pencarian** | Temukan film favorit dengan cepat |
| 📄 **Detail Film** | Sinopsis, informasi lengkap, dan tombol putar instan |
| ▶️ **Pemutar Video** | Mode landscape layar penuh dengan kontrol lengkap |
| ⬇️ **Unduhan** | Simpan tontonan untuk dilihat tanpa internet |
| 🕘 **Riwayat** | Lanjutkan tontonan terakhir tanpa repot |
| ⚙️ **Pengaturan** | Atur aplikasi sesuai seleranmu |
| 📺 **Dukungan TV** | Tampilan khusus untuk layar Android TV |

## 🛠️ Teknologi

- **Bahasa:** Kotlin
- **UI:** Jetpack Compose
- **Arsitektur:** MVVM
- **Platform:** Android (Mobile & TV)

## 📦 Instalasi

```bash
# 1. Clone repositori
git clone https://github.com/USERNAME/MikdadStreaming.git

# 2. Buka folder proyek
cd MikdadStreaming

# 3. Buka dengan Android Studio, tunggu Gradle sync selesai,
#    lalu klik Run ▶️
```

> Ganti `USERNAME` dengan username GitHub kamu.
